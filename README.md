# Vetri Tamil Nadu - Citizen Services Portal

![Vetri Tamil Nadu](https://img.shields.io/badge/Status-Active-success) ![Tech Stack](https://img.shields.io/badge/Tech%20Stack-HTML5%20%7C%20CSS3%20%7C%20JS-blue)

A modern, responsive, and premium web application designed to serve as a comprehensive citizen portal for the people of Tamil Nadu. The platform features a cinematic, glassmorphism-inspired UI with rich micro-animations, multi-language support (English/Tamil), and an array of citizen-centric features.

---

## 🌟 Key Features

* **Multi-Language Support:** Seamlessly toggle between English and Tamil across the entire application.
* **Premium UI/UX:** Built with modern design principles including glassmorphism cards, CSS Grid masonry layouts, floating animations, and ripple effects.
* **CM Vijay Gallery:** A cinematic photo gallery featuring masonry grids, auto-sliding hero banners, category filters, and a full-screen lightbox.
* **Scheme Eligibility Checker:** An intelligent, client-side tool where users input demographics (Age, Income, District, etc.) to instantly find matching government welfare schemes.
* **District Wise Dashboard:** A localized portal providing dynamic local news, current weather, emergency contacts, and specific schemes based on the selected district.
* **Donation & Payment Dashboard:** A custom-built premium payment UI featuring amount selection cards, simulated QR/UPI generation, and animated success popups.
* **Complaint Portal:** A robust grievance redressal system with a multi-step form and a vertical tracking timeline utilizing generated Complaint IDs.
* **Emergency & Weather:** Live weather cards with disaster alerts and one-tap SOS emergency contacts integrated directly into the dashboard.

## 🛠️ Technology Stack

* **Structure:** HTML5
* **Styling:** CSS3 (Vanilla CSS, CSS Grid, Flexbox)
* **Interactivity:** Vanilla JavaScript (ES6+)
* **Typography:** Google Fonts (Poppins, Noto Sans Tamil)
* **Icons:** FontAwesome 6

## 🚀 Getting Started

To run this project locally, follow these simple steps:

### Prerequisites
* Node.js installed (optional, only needed for running a local dev server)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/srivatsan2007/Vetri-Tamil-Nadu.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Vetri-Tamil-Nadu
   ```
3. **Run locally:**
   * **Option A:** Simply open `index.html` in your favorite browser.
   * **Option B:** If you prefer using a local server, you can run the included simple Node server:
     ```bash
     node server.js
     ```
     Then open `http://localhost:3000` in your browser.

## 📱 Responsiveness

The portal is fully optimized for all devices. It uses CSS `clamp()` for fluid typography and dynamic grid layouts to ensure a beautiful experience on desktops, tablets, and mobile phones.
